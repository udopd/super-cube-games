SDK contract · v1.1

Browser SDK calls are requests to the platform, not a trusted source of truth. Keep game rules local only for single-player presentation; validate scores, state transitions and multiplayer actions on the server. Use stable game slugs, await SDK calls, handle guest mode and network failures, and never place credentials in the archive.
